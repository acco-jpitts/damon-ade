---
name: db-migrate
description: Create a database migration for packages/db using Drizzle and a scratch Neon branch. Use when asked to add/change a DB schema, generate a migration, or touch packages/db/drizzle.
---

- Always spin up a new Neon branch to create migrations. Update the root `.env` files to point at the Neon branch locally.
- `NEON_ORG_ID` and `NEON_PROJECT_ID` env vars are set in `.env`; the `list_projects` tool requires `org_id` passed in.
- Change the Drizzle schema at `packages/db/src/schema`, then run `bunx drizzle-kit generate --name="<sample_name_snake_case>"`.
- Never run the migration yourself — ask the user to run it.
- Never manually edit files in `packages/db/drizzle/` (`.sql` files, `meta/_journal.json`, snapshots) — these are auto-generated by Drizzle. Only modify `packages/db/src/schema/` and ask the user to run `drizzle-kit generate`.
